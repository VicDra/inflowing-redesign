# Редизайн inflowing.ru

Три концепта главной страницы для студии In Flow («Пространство души и тела», Санкт-Петербург).

Сайт: https://vicdra.github.io/inflowing-redesign/

| Файл | Что внутри |
|---|---|
| `index.html` | Стартовая страница со ссылками на концепты |
| `concept-1-monolith/` | Концепт 1 «Монолит»: тёмный, поток частиц, партитура визита |
| `concept-2-elements/` | Концепт 2 «Стихии»: светлый, колонны стихий, встроенный квиз |
| `concept-3-lab/` | Концепт 3 «Лаборатория состояния»: дышащая сфера, подбор программы, запись |

Каждый концепт — один самодостаточный HTML-файл без сборки. Шрифты загружаются с Google Fonts.

## Просмотр

```bash
python -m http.server 8765
```

Затем откройте http://localhost:8765.

## Ограничения

- Фото пространства и мастеров заменены генеративной графикой.
- Формы демонстрационные и ничего не отправляют.
- Тексты отзывов, занятые слоты записи и минуты отдельных практик — заглушки или оценки.
